# 错误记录文件夹说明

## 1. 用途

本文件夹用于存储ESP32智能家居控制系统的错误记录和相关文档，旨在提高系统的可维护性和故障排查效率。

## 2. 文件夹结构

```
errors/
├── error_log.md           # 错误日志记录文件
├── error_specification.md  # 错误规范文档
└── README.md              # 本说明文件
```

## 3. 错误规范

详细的错误规范请参考 `error_specification.md` 文件，其中包含：

- 错误分类（系统级和模块级）
- 错误代码格式（8位十六进制）
- 错误记录格式（JSON结构）
- 错误处理流程
- 错误代码表

## 4. 错误日志管理

### 4.1 日志存储
- 临时日志：存储在RAM缓冲区，重启后丢失
- 持久化日志：存储在SPIFFS文件系统中

### 4.2 日志命名规则

日志文件采用以下命名规则：

```
error_log_YYYYMMDD_HHMMSS.log
```

例如：`error_log_20240101_120000.log`

### 4.3 日志格式

每个日志条目采用JSON格式，包含以下字段：

```json
{
  "timestamp": "2024-01-01T12:00:00Z",
  "error_code": "030101",
  "error_level": "ERROR",
  "module": "WiFiManager",
  "function": "connect()",
  "description": "WiFi连接超时",
  "additional_info": "SSID: my_wifi"
}
```

## 5. 使用指南

### 5.1 记录错误

当系统发生错误时，应按照以下步骤记录：

1. 根据错误规范确定错误代码
2. 收集错误相关信息（时间、模块、函数等）
3. 按照日志格式创建日志条目
4. 将日志条目写入适当的日志文件

### 5.2 查看错误

可以通过以下方式查看错误日志：

1. 通过串口查看实时日志
2. 通过Web界面查看历史日志
3. 通过文件系统直接访问日志文件

### 5.3 排查错误

根据错误日志排查问题时，应：

1. 查看错误代码，确定错误类型和模块
2. 分析错误描述和额外信息
3. 参考错误规范文档中的解决方案
4. 记录问题解决过程和结果
