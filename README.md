# ESP32智能家居控制系统

## 🚀 快速开始 - 5分钟上手

这是一个**超级简单**的智能家居控制系统，只要按照步骤操作，**傻子都能学会**！

### 第一步：准备硬件（必须有）
- ESP32开发板（推荐ESP32-DevKitC）
- USB-C数据线（用来连接电脑和ESP32）
- 一颗好奇心 😊

### 第二步：安装软件
1. 下载Arduino IDE：[点击这里](https://www.arduino.cc/en/software)
2. 安装后打开Arduino IDE
3. 按照后面的「详细安装步骤」配置ESP32支持

### 第三步：上传代码
1. 打开`led_control.ino`文件（用Arduino IDE打开）
2. 修改WiFi名称和密码（按提示改）
3. 点击右上角「上传」按钮
4. 等待上传完成（看到「上传成功」就行）

### 第四步：使用系统
1. 打开「串口监视器」看IP地址
2. 在浏览器输入IP地址
3. 开始控制你的智能设备！

## 🔌 硬件连接图（傻瓜式）

### 最简单版（只用板载LED，不用额外设备）
**什么都不用接！** 直接用ESP32板载的LED（通常在GPIO2）

### 进阶版（接LED和传感器）

#### LED连接：
```
ESP32 GPIO4 ────────[220Ω电阻]─────── LED正极
ESP32 GND ──────────────────────────── LED负极
```

#### 传感器连接：
```
ESP32 GPIO14 ─────── DHT11/DHT22数据引脚
ESP32 GPIO32 ─────── 光敏电阻信号引脚
ESP32 GPIO33 ─────── MQ-2烟雾传感器信号引脚
ESP32 GPIO17 ─────── 有源蜂鸣器信号引脚
```

**注意：** 所有传感器都需要接3.3V电源和GND！

## 💻 软件安装和配置（精确到按钮）

### 1. 安装Arduino IDE
1. 打开浏览器，访问：https://www.arduino.cc/en/software
2. 点击「Download」下载适合你系统的版本
3. 安装时一直点「Next」，最后点「Finish」

### 2. 配置ESP32支持
1. 打开Arduino IDE
2. 点击顶部菜单：**文件** → **首选项**（或者按Ctrl+,）
3. 在「附加开发板管理器网址」框里粘贴：
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
4. 点击「好」保存

### 3. 安装ESP32开发板
1. 点击顶部菜单：**工具** → **开发板** → **开发板管理器...**
2. 在搜索框输入「ESP32」
3. 找到「ESP32 by Espressif Systems」
4. 点击「安装」按钮（可能需要几分钟）
5. 安装完成后点击「关闭」

### 4. 选择开发板和端口
1. 点击顶部菜单：**工具** → **开发板** → 选择「ESP32 Dev Module」
2. 点击顶部菜单：**工具** → **端口** → 选择连接ESP32的COM端口（通常是COM3、COM4等）

### 5. 安装所需库
1. 点击顶部菜单：**工具** → **管理库...**
2. 在搜索框输入「WiFi」，找到「WiFi」库，点击「安装」
3. 同样方法安装：「ArduinoJson」、「ESPAsyncWebServer」、「AsyncTCP」
4. 如果要用DHT传感器，安装「DHT sensor library」
5. 全部安装完成后点击「关闭」

## 📤 上传代码（精确到按钮）

### 使用简易版代码（推荐新人）
1. 点击顶部菜单：**文件** → **打开**
2. 找到项目文件夹，选择 `led_control.ino` 文件
3. 在代码里找到这两行，修改成你的WiFi信息：
   ```cpp
   const char* ssid = "你的WiFi名称";
   const char* password = "你的WiFi密码";
   ```
4. 点击右上角的**上传按钮**（→ 图标）
5. 等待编译和上传，看到「上传成功」就完成了！

**注意：** 如果上传失败，按住ESP32上的「BOOT」按钮再点击上传

## 🖥️ 使用Web界面（精确到步骤）

### 1. 获取ESP32的IP地址
1. 点击顶部菜单：**工具** → **串口监视器**（或按Ctrl+Shift+M）
2. 右下角波特率选择「115200」
3. 等待几秒，你会看到类似这样的信息：
   ```
   WiFi connected
   IP address: 192.168.1.100
   ```
4. 记住这个IP地址（比如192.168.1.100）

### 2. 访问Web界面
1. 打开电脑或手机的浏览器（推荐Chrome或Firefox）
2. 在地址栏输入刚才的IP地址（比如：http://192.168.1.100）
3. 按回车，你会看到智能家居控制系统的界面！

### 3. 控制设备
- **智能灯控制**：
  1. 找到「智能灯」区域
  2. 点击「开关」按钮可以打开/关闭LED
  3. 拖动「亮度」滑块可以调节LED亮度

- **智能开关控制**：
  1. 找到「智能开关」区域
  2. 点击「开关」按钮可以控制开关状态

- **环境监测**：
  1. 在界面上可以看到温度、湿度、光照强度、烟雾浓度
  2. 数据会自动刷新（每秒更新一次）

## ✨ 功能说明

### 🎛️ 设备控制
- **智能灯**：支持开关和亮度调节（0-100%）
- **智能开关**：支持开关控制，可用于控制其他设备
- **状态同步**：所有设备状态实时更新到Web界面

### 🌡️ 环境监测
- **温度监测**：实时显示当前温度（℃）
- **湿度监测**：实时显示当前湿度（%）
- **光照监测**：实时显示当前光照强度（lx）
- **烟雾监测**：实时显示烟雾浓度（ppm）

### 🤖 自动化功能
- 可以设置规则，比如：
  - 光照太暗时自动开灯
  - 温度太高时自动打开风扇
  - 烟雾浓度超标时自动报警

### 📊 数据展示
- Web界面实时显示所有数据
- 数据会自动存储到ESP32本地
- 支持查看历史数据

## ❌ 故障排除 - 常见问题

### 📶 WiFi连接不上
- **问题**：串口监视器显示「Failed to connect WiFi」
- **解决**：
  1. 检查WiFi名称和密码是否正确（注意大小写）
  2. 确保WiFi是2.4GHz的（ESP32不支持5GHz）
  3. 靠近路由器试试
  4. 重启ESP32和路由器

### 🖥️ 访问不了Web界面
- **问题**：浏览器显示「无法连接」
- **解决**：
  1. 确保电脑/手机和ESP32在同一WiFi网络
  2. 检查IP地址是否正确
  3. 关闭电脑的防火墙试试
  4. 重新上传代码

### 💡 LED不亮
- **问题**：点击开关后LED没反应
- **解决**：
  1. 检查LED接线是否正确
  2. 确保电阻接对了
  3. 试试直接用3.3V电源测试LED是否坏了
  4. 检查代码里的引脚定义是否正确

### 📤 上传失败
- **问题**：Arduino IDE显示「上传失败」
- **解决**：
  1. 检查USB线是否插紧
  2. 按住ESP32上的「BOOT」按钮再上传
  3. 确认开发板选择的是「ESP32 Dev Module」
  4. 确认端口选择正确

## 🎯 进阶使用

### 使用完整版代码
1. 完整版代码在 `src/main.cpp` 里
2. 包含更多功能：规则引擎、告警系统、数据存储
3. 配置方法：修改 `include/config.h` 文件里的WiFi信息

### 示例代码
项目提供了两个示例代码：
- `examples/basic_device_control/`：基本设备控制示例
- `examples/advanced_automation/`：高级自动化示例

### 添加新设备
1. 在 `src/devices/` 目录下创建新的设备类
2. 继承自 `Device` 基类
3. 在主程序中注册设备
