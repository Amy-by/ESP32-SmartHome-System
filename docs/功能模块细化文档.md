# 基于ESP32的智能家居控制系统功能模块细化文档

## 1. 设备控制模块

### 1.1 实现概述

设备控制模块采用面向对象设计，通过抽象类`Device`定义了所有智能设备的统一接口，然后派生出具体的设备类如`SmartLight`和`SmartSwitch`。`DeviceManager`类负责管理所有设备，提供设备的添加、移除、状态查询和更新等功能。

### 1.2 类关系图

```
┌─────────────┐
│   Device    │  <── 抽象类
└─────┬───────┘
      │
      ├──┬─────────────┐
      │  │             │
┌─────▼───▼────┐ ┌─────▼───▼────┐
│  SmartLight  │ │  SmartSwitch │  <── 具体实现类
└──────────────┘ └──────────────┘

┌────────────────┐
│ DeviceManager  │  <── 设备管理类
└────────────────┘
```

#### 使用说明
Device类是一个抽象类，不能直接实例化。所有具体设备类都应继承自此类并实现其纯虚函数。

```cpp
deviceManager.addDevice(switch);

// 控制设备

deviceManager.updateDeviceStatus("switch_1", true);

// 获取设备状态

// 获取所有设备
vector<Device*> devices = deviceManager.getAllDevices();
```

```cpp
    String sensorId;      // 传感器ID
```

```cpp
struct AlarmAction {
    String deviceId;      // 设备ID
```

### 10.3 错误代码系统

错误代码采用8位十六进制格式（XXYYZZ），详细规范请参考`errors/error_specification.md`文件。

| 错误类型 | 代码范围 |
|---------|---------|
| 硬件错误 | 010000 - 01FF00 |
| 软件错误 | 020000 - 02FF00 |
| 通信错误 | 030000 - 03FF00 |
| 配置错误 | 040000 - 04FF00 |

### 10.4 错误处理流程

1. **错误检测**：各模块在执行操作时检测错误
2. **错误记录**：调用`ErrorHandler::logError()`记录错误详细信息
3. **错误传播**：将错误信息返回给调用者
4. **错误处理**：调用者根据错误信息采取适当的处理措施
5. **错误恢复**：对于可恢复错误，尝试自动恢复操作
6. **错误报告**：通过Web界面或API向用户报告错误
